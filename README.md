# TomTroc - Projet de formation 4 Developpeur Full-Stack - OpenClassrooms

Application web de mise en relation entre particuliers pour l'échange de livres

## Technologies

- PHP (POO/MVC)
- MySQL
- HTML / CSS
- JavaScript

## Architecture

- 4 contrôleurs
- 4 entités et leurs repositories
- Vues PHP
- Routeur principal index.php

## État du projet

- Architecture initiale créée
- Base de données opérationnelle
- Entités définies et opérationnelles
- Footer/header communs et vue Accueil, intégration graphique partielle (non-responsive)
- Page Catalogue + barre de recherche implémentés et fonctionnels
- Page de détail d'un livre (graphiquement adaptée, voir journal de développement)
